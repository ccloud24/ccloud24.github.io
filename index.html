Trends2Alpha

I wanted to see whether search interest could add anything useful to a basic market model, so I built a pipeline to test it.

It pulls Google Trends and Yahoo Finance data, lines up the time series, builds features, trains Random Forest models, and runs a chronological backtest. I also wrote down the important caveats, including execution costs and the risk of look-ahead bias.

  • Python
  • Pandas
  • scikit-learn
  • APIs
  • Time series

The version in the repo tests five stocks with about 20 features each. Each model uses 200 trees; the reported AUCs range from 0.867 to 0.956.
